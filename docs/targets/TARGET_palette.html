Rainbow palettes, each in one key

TARGET v1. Approved 2026-10-09: "Clear" ONLY. Jewel and Pastel-bright are not chosen. Read-only.

Each palette keeps the same brightness and the same strength of colour across all eight hues, and only changes the hue. That is what makes colours feel like one family. Today's set mixes very bright gold and orange with darker slate and teal, which is why it clashes. Each palette includes a green, because a rainbow needs one; it can be swapped out.
